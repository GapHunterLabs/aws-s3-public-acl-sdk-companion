Reports an AWS SDK for Java call in application code that makes an S3 bucket or object public: SDK 1.x setBucketAcl(bucket, CannedAccessControlList.PublicRead), withCannedAcl(...) or setCannedAcl(...), and SDK 2.x .acl(ObjectCannedACL.PUBLIC_READ) or .acl("public-read").

A public ACL set from code exposes data the same way as a misconfigured bucket policy, but it does not show up in infrastructure-as-code scanners, because it happens at runtime.
